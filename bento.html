Craft CMS · AI Agent

A site-aware agent built into your control panel.

Craft AI gives editors and developers an LLM that can read and write Craft entries, drafts, sections, fields, templates, and assets — running as the current user, with every tool gated by Craft permissions.

Review comments

The agent leaves inline feedback — and resolves it.

Run /review entry:123 and the agent inspects every field, leaves targeted comments on the ones that need work, and resolves them later once they're addressed. Comments scope to fields, Matrix blocks, and even specific spans inside CKEditor text. Opening a thread forks a private discussion session so multiple comments never trample on each other.

Permission-checked tools

Every tool runs as the current Craft user.

Tools carry a kind (read, draftWrite, liveWrite) and are gated by Craft permissions. An editor who can't publish to a section can't trick the agent into doing it either — and an MCP client gets only the operations its bound user can run.
